# home-portal-data

Зашифрованные данные для Home Portal — личного портала домашних дел.
Данные публикуются плагином из Obsidian и читаются клиентом
[home-portal-client](https://github.com/ahrenizmic/home-portal-client).

## Что здесь лежит

Репозиторий публичный, но данные зашифрованы (AES-GCM, ключ выводится из
пароля через PBKDF2). Без пароля содержимое не прочитать.

| Файл             | Что это                                                        |
|------------------|----------------------------------------------------------------|
| `data`           | Зашифрованный bundle: проекты, задачи, события. Формат: `iv(12 байт) + ciphertext`. |
| `manifest`       | Зашифрованные метаданные публикации. Внутри: `formatVersion`, `publishedAt`, `publishId`. Тот же формат упаковки, что у `data`. |
| `keyparams.json` | Параметры вывода ключа (открытые): алгоритм KDF, число итераций, соль. Пароля здесь нет. |

`publishId` — SHA-256 от содержимого bundle. Меняется только когда меняются
данные. Клиент по нему понимает, нужно ли перекачивать `data`.

## Как обновляются данные

Публикацией из Obsidian: плагин Home Portal, кнопка опубликовать (слева на панели).
Плагин собирает bundle, шифрует и коммитит `data`, `manifest`, `keyparams.json`
в этот репозиторий.

## Безопасность

- Всё, кроме пароля, открыто — стойкость обеспечивает только пароль.
- Соль в `keyparams.json` не секрет (так и задумано для PBKDF2).
- Пароль нигде не хранится и не передаётся.
